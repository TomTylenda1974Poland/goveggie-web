# GoVeggie brand names

Always write **Palapa Verde** exactly this way in every language. Keep the brand name intact in translations, links, and calls to action. Mark visible occurrences with `translate="no"` for browser translation.

## Produce imagery

For kitchen scenes, use the current Go Veggie Life engraving style: graphite linework on white for people, crates and equipment, with natural colour concentrated on the food. Every visible crate label must identify the produce it actually holds. Write the names clearly in Spanish for the local version and use natural English for its translated counterpart. Use “fresco” or “fresca” where it accurately describes the produce. Only use dated picking, packing, storage or shelf-life statements when supplied for that batch. Check label legibility and the composition at laptop width before publishing.
