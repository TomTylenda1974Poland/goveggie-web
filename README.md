# GoVeggie — sitio web (prototipo de producción)

Sitio estático de Go Veggie Life (goveggie.life) — identidad "Modern Botanical Heritage".

- Páginas: `index.html`, `productos.html`, `supermercados.html`, `nosotros.html`, `contacto.html`
- Estilos: `assets/site.css` · Imágenes: `assets/*.jpg` (servidas vía jsDelivr CDN)
- Despliegue: Vercel (cuenta GoVeggie) — las páginas referencian las imágenes de este repo vía CDN.
- Idiomas: ES (principal) / EN (toggle)

Prototipo: logo, datos de contacto y declaraciones son de ejemplo hasta aprobación final.
